# 雪山缆车救援行动

一个纯前端 3D 操作型救援游戏，使用 React、Vite、TypeScript、React Three Fiber 和 Three.js 构建，不包含后端服务。

## 操作

- `WASD` / 方向键：移动救援员
- `Shift`：冲刺，消耗体力
- `Q` 对应按钮：打入冰镐锚点
- `E` 对应按钮：靠近受困者且已有锚点时连接救援绳，进入“撤离中”状态
- 撤离阶段：受困者经主绳跟随救援员，必须护送其返回出发点附近的绿色安全区才算救援成功；途中体力、体温与绳长持续消耗，任一耗尽即失败
- `R` 对应按钮：收紧救援绳
- 拖拽场景：旋转观察视角
- 滚轮：缩放

## 启动

```bash
npm install
npm run dev
```

当前为单机基础版本，游戏状态保存在内存中。后续可扩展攀爬动画、绳索物理、雪崩事件、体力恢复点、关卡编辑器和本地存档。
